MOTION AI - personal motion-graphics learning prototype

1. Put your exported CapCut videos into input/training/
2. Install: pip install -r requirements.txt
3. Run: python analyzer/analyze_style.py
4. The first style profile is written to style_memory/style_memory.json

This first analyzer learns measurable video-level patterns. Later versions will add automatic scene, text, color, transition, and motion-pattern analysis, followed by generation and feedback learning.
